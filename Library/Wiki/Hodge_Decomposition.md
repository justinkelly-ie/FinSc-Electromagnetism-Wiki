## 2. Mathematical Principle

Any arbitrary electromagnetic state vector field $V$ mapped over a causal substrate grid decomposes into three mutually orthogonal physical components:

$$V = V_{\text{harmonic}} \oplus \nabla \Phi \oplus (\nabla \times \mathbf{A})$$

1. **Harmonic Field ($V_{\text{harmonic}}$)**: Vacuum radiation modes satisfying $\Delta V = 0$.
2. **Gradient Field ($\nabla \Phi$)**: Pure irrotational electrostatic fields generated by scalar charge potentials.
3. **Curl Field ($\nabla \times \mathbf{A}$)**: Solenoidal magnetostatic fields generated by closed current loops.

prop_hodgeVacuumOrthogonality = property (
  let (MkHodge harm grad curl) = decomposeEMField emptyVexel emptySubstrate
  in harm == emptyVexel && grad == emptyVexel && curl == emptyVexel)

public export
prop_hodgeReconstructionVacuum : Property
prop_hodgeReconstructionVacuum = forAll {a = Geometry} {prop = Bool} arbitrary (MkFn (\g =>
  let field = singletonVexel g emptyIntPoly
